AI-Powered Hybrid Chatbot

An intelligent chatbot using Python, Flask, and NLP that:  
- Handles polite rule-based greetings  
- Answers factual questions via Wikipedia API  
- Falls back to DialoGPT-small for safe free-form chat  
- Supports multiple users with separate chat histories  
- Logs conversations in SQLite

Technologies
Python 3.12, Flask, Transformers, DialoGPT-small, NLTK, Wikipedia API, SQLite
